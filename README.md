# Linuxshell Press

Repository pubblico del materiale tecnico associato ai libri **Linuxshell Press**.

Il repository raccoglie script, configurazioni e altri file operativi citati nei volumi. Il materiale è organizzato prima per libro e poi per capitolo o laboratorio, in modo da mantenere un unico archivio tecnico comune alla collana.

## Libri

### Noi Amministriamo Infrastrutture Linux

- [Laboratorio – Provisioning automatico di VM Linux da golden image](./noi-amministriamo-infrastrutture-linux/laboratorio-provisioning-golden-image/)

## Verifica dei file

Gli script validati nel laboratorio sono accompagnati dal relativo SHA-256. I checksum complessivi disponibili sono raccolti in [SHA256SUMS](./SHA256SUMS).

## Licenza

Il repository è distribuito secondo i termini indicati nel file [LICENSE](./LICENSE).

Quando un libro cita una specifica revisione di uno script, nome del file e SHA-256 permettono di verificare che il contenuto scaricato corrisponda alla versione collaudata e descritta nel testo.
