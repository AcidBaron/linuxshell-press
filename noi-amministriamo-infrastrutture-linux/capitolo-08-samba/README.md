## Convenzioni

- `comandi.md` mantiene i blocchi operativi nell'ordine del testo.
- `configurazioni/` contiene lo stato finale validato quando il capitolo lo riporta integralmente.
- `diagnostica/` contiene prove temporanee o workaround usati per isolare un problema: **non è lo stato finale**.
- `legacy/` contiene equivalenti storici realmente provati: **non sostituisce la configurazione moderna finale**.

> Il libro resta la fonte narrativa e procedurale autorevole. Prima di riutilizzare un file verificare nomi delle interfacce, indirizzi e prerequisiti del proprio ambiente.
